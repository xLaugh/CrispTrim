## CrispTrim 0.3.2 : reprises, respirations, coupes à la main et audio monté

- **Reprises** : quand tu rates une phrase et que tu la recommences, CrispTrim coupe l'essai raté et garde
  la dernière version (en rose sur la timeline). Les bégaiements (« le le ») sont coupés aussi.
  Interrupteur « Couper les reprises » dans les réglages.
- **Respirations** : les inspirations entre les phrases sont repérées (en bleu clair). Tu choisis de les
  couper, de les atténuer dans la vidéo montée, ou de les garder.
- **Claquements de bouche** : un filtre les atténue dans la vidéo montée (activé par défaut).
- **Coupes à la main** : Maj + glisser sur la timeline coupe la zone choisie (en rouge). Ctrl + Z annule
  la dernière.
- **Zoom plus doux** : Ctrl + molette zoome progressivement sur la timeline.
- **Audio monté** : nouveau bouton pour exporter seulement le son, avec les mêmes coupes, en WAV, MP3,
  FLAC ou M4A. En ligne de commande : `--export wav,mp3`.

Prends **`CrispTrim-Setup.exe`** (installateur) ou **`CrispTrim.exe`** (portable). Si tu as déjà
CrispTrim, « Nouvelle version disponible » > *Mettre à jour* suffit. `crisptrim-gpu.exe` est téléchargé
automatiquement par CrispTrim sur les PC NVIDIA.
